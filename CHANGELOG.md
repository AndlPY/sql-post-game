# Changelog

## 0.2.0 — 2026-09-16

- Robot: travel durations doubled, eased arrival, readable pickup sequence and pause at handoff; home/delivery beside the player clerk.
- Mistakes reduce the current customer's potential payment by 5; saved coins are never deducted. Third mistake: client leaves unpaid.
- Natural customer dialogue; correct parcel accepted with any selection containing id. Bonus uses a weight clue in grams while the register uses kilograms.
- Smaller sidebar typography; more editor/preview space; Run at the bottom; automatic matching single/double quotes.
- Generated pixel-art reward stars and centered summary. Separate total served /13, main /12 and bonus status.
- Version displayed in UI, file map in README, GitHub Pages workflow, expanded future tutorial backlog.

## 0.1.0 — 2026-09-16

- First local playable prototype: PGlite Worker, Phaser scene, SQL editor/preview, 13 orders and local profile.
- This prototype deducted penalties from wallet; 0.2.0 corrects that misunderstanding. Existing local coins are kept as stored; no speculative retroactive refund.
