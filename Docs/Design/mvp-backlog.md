## Зафіксовані рішення

- Web, single-player, Windows у пріоритеті; desktop Chrome/Edge/Firefox. Full HD — основний орієнтир, UI помірно адаптивний до звуження вікна. Mobile поза MVP.
- TypeScript + Phaser + HTML/CSS UI. Gameplay v3 — візуальна ціль. Суттєві відхилення погоджувати, повідомляти про проблеми відтворення.
- UI будується кодом із pixel-style рамками, кольорами та ефектами, а не картинкою з неробочими текстами й кнопками. Використовувати наявні scene assets.
- PostgreSQL через PGlite у Web Worker — перший вибір; SQLite лише за виявленої суттєвої несумісності. SQL навчальної бази не має доступу до збережень профілю.
- Безкоштовний hosting, поточний вибір GitHub Pages, repository sql-post-game; без платного domain і backend. Публікація — після перевірки build та доступу до account.
- Один локальний профіль: nickname, стать персонажа, монети, пройдені рівні й найкращі зірки. Немає Auth, cloud save, кількох локальних профілів.
- Прогрес усередині рівня не зберігається. Після повторного входу рівень починається спочатку. Монети зберігаються після успішної видачі. Помилки зменшують лише оплату поточного клієнта, не wallet.
- Попереджати про втрату прогресу зміни всередині гри й через beforeunload, коли browser дозволяє. Browser контролює текст і надійність системного попередження.
- Українські UI, репліки, імена й прізвища; таблиці/поля англійською, кольори можна англійською.
- 1 рівень: SELECT, FROM, вибір полів, WHERE =; 4 легкі + 4 середні + 4 повторні + 1 бонусний. Дані фіксовані; порядок формується за когортами при кожному запуску.
- 3 помилки — клієнт іде без оплати; кожна помилка зменшує майбутню оплату цього клієнта на 5, мінімум оплати 0. Баланс не зменшується. Винагороди 10/20/30, максимум 190; 3★ за 12/12 основних; бонус не змінює зірки.
- Робот перевозить одну коробку. Повідомити про місткість у tutorial та UI. Час руху вдвічі більший за v0.1.0; уповільнення біля pickup/handoff та читабельні паузи. База робота й видача поруч із працівником. Неправильна коробка повертається.
- Полиці та фонові коробки не змінювати. Робот бере коробки збоку/вдалині; віддзеркалення pickup дозволене. Зникнення виданих рядків з бази — після основних задач.
- Tutorial: спочатку UI, потім SQL і окрема демонстрація до оцінюваних клієнтів. Можна пропустити/повторити. Повторні пояснення наставника без демонстрації; немає окремих підказок до кожного замовлення.
- SQL highlighting; без keyword autocomplete. Доповнення назв таблиць і полів допустиме, але не обов'язкове для першої збірки.
- Для MVP 3 клієнти: капелюх, рудоволоса, червоний берет. Оливкова куртка зберігається як запасний asset. Не генерувати 30 персонажів.
- Morning — музика лише меню; SFX відкладені, список нижче. Audio запускається після взаємодії з гравцем, браузер може блокувати autoplay.

## SFX — після музики меню

1. Правильна видача — короткий приємний сигнал підтвердження.
2. Неправильна видача — м'який сигнал, без різкого покарання.
3. Run — коротке прийняття команди роботом.
4. Рух робота — дуже короткий механічний проїзд під 0,5–1 с доставки.
5. Захоплення / повернення коробки — невеликий механічний click.
6. Монети — коротка винагорода без довгої послідовності дзвону.
7. Завершення рівня й поява зірок.
8. UI click і відкриття панелі наставника.
9. Вхід/вихід клієнта, тихі кроки.
10. Особлива видача золотої коробки.
11. Ненав'язливий ambience поштового відділення.
12. Додаткова фонова музика — лише за потребою; Morning уже призначена для меню.

Після додавання: mute, окремі рівні music/SFX, збереження налаштувань, запуск audio після взаємодії користувача, не накладати дублікати при повторних подіях. Підготувати короткі файли та перевірити право використання.

## Анімації — деталі реалізації

1. **Натискання кнопки — UI.** Кнопка `Run` та інші кнопки коротко втискаються й повертаються у звичайний стан.
2. **Результат запиту — UI.** Коротка підсвітка успішного результату або легке похитування повідомлення про помилку.
3. **Поява пояснення — наставник і клієнти.** Портрет разом із текстовою панеллю плавно з’являється та зникає.
4. **Оновлення прогресу — HUD.** Смуга обслугованих клієнтів плавно заповнюється; лічильник монет коротко підсвічується після винагороди.
5. **Дихання — працівник, працівниця, наставник і клієнти в idle (з чату).** Ледь помітне підняття плечей і грудей; стопи залишаються на місці. Персонажі дихають несинхронно.
6. **Обертання коліс — робот під час руху (з чату).** Видимі колеса обертаються відповідно до швидкості та зупиняються разом із роботом; корпус залишається стабільним.
7. **Кліпання — люди в idle та їхні портрети (з чату).** Очі ненадовго заплющуються через нерівні проміжки часу; решта обличчя нерухома.
8. **Очікування — клієнти в черзі.** Зрідка трохи переносять вагу з ноги на ногу, залишаючись на своєму місці.
9. **Реакція екрана — робот.** Коротка зміна яскравості очей після отримання команди або захоплення посилки.
10. **Інерція вантажу — робот із посилкою.** На початку руху й під час зупинки руки та коробка ледь погойдуються разом, без ковзання коробки в захваті.

### Tutorial

11. **Підсвічування поточного UI-елемента.** М'який pulse рамки без блокування решти гри під час покрокового пояснення; усі елементи залишаються клікабельними. Кроки Далі/Назад/Пропустити керують підсвічуванням.
12. **Стрілки наставника.** Стрілка спрямована на елемент поточного кроку, перераховується при resize, не перекриває текст/click target.
13. **Портрети наставника.** Зміна підготовлених жестів між інструкціями UI та SQL; коротка поява панелі внизу екрана. Демонстраційний клієнт окремий, без монет.
