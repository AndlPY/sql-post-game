# Анімації кодом

Порядок виконання: спочатку корисне для MVP та просте, далі — додаткове й складніше. Позначка «з чату» — раніше обговорена ідея; решта — пропозиції.

1. **Натискання кнопки — UI.** Кнопка `Run` та інші кнопки коротко втискаються й повертаються у звичайний стан.
2. **Результат запиту — UI.** Коротка підсвітка успішного результату або легке похитування повідомлення про помилку.
3. **Поява пояснення — наставник і клієнти.** Портрет разом із текстовою панеллю плавно з’являється та зникає.
4. **Оновлення прогресу — HUD.** Смуга обслугованих клієнтів плавно заповнюється; лічильник монет коротко підсвічується після винагороди.
5. **Дихання — працівник, працівниця, наставник і клієнти в idle (з чату).** Ледь помітне підняття плечей і грудей; стопи залишаються на місці. Персонажі дихають несинхронно.
6. **Обертання коліс — робот під час руху (з чату).** Видимі колеса обертаються відповідно до швидкості та зупиняються разом із роботом; корпус залишається стабільним.
7. **Кліпання — люди в idle та їхні портрети (з чату).** Очі ненадовго заплющуються через нерівні проміжки часу; решта обличчя нерухома.
8. **Очікування — клієнти в черзі.** Зрідка трохи переносять вагу з ноги на ногу, залишаючись на своєму місці.
9. **Реакція екрана — робот.** Коротка зміна яскравості очей після отримання команди або захоплення посилки.
10. **Інерція вантажу — робот із посилкою.** На початку руху й під час зупинки руки та коробка ледь погойдуються разом, без ковзання коробки в захваті.

## Tutorial — після v0.2.0, зараз не реалізовувати

11. **Підсвічування поточного UI-елемента.** М'який pulse рамки та затемнення решти екрана під час покрокового пояснення; активний target залишається клікабельним. Кроки Далі/Назад/Пропустити керують підсвічуванням.
12. **Стрілки наставника.** Стрілка спрямована на елемент поточного кроку, перераховується при resize, не перекриває текст/click target.
13. **Портрети наставника.** Зміна підготовлених жестів між інструкціями UI та SQL; коротка поява панелі внизу екрана. Демонстраційний клієнт окремий, без монет.
