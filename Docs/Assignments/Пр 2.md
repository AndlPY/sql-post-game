# **Практична робота №2**

## **Створення навчального квесту з елементами гейміфікації**

### **Мета роботи**

Навчитися створювати прості навчальні завдання з використанням елементів гейміфікації.

### **Завдання**

Створити **невеликий навчальний квест**, який можна використати під час вивчення обраної дисципліни.  
Квест повинен складатися з **5 послідовних завдань**. За виконання кожного завдання студент отримує бали, а після проходження всього квесту — нагороду.

## Хід роботи

### 1\. Оберіть тему

Оберіть будь-яку навчальну дисципліну та конкретну тему.  
Наприклад:

* Англійська мова — «Подорож»;  
* Інформатика — «Комп'ютерні мережі»;  
* Програмування — «Умовні оператори»;  
* Історія — «Київська Русь»;  
* Математика — «Відсотки».

### 2\. Придумайте назву та легенду квесту

Придумайте цікаву назву та коротку історію на 3–5 речень.  
Приклад:  
Назва: «Врятувати цифрове місто»  
Легенда: У цифровому місті стався збій. Щоб відновити систему, команда повинна пройти п'ять рівнів. На кожному рівні необхідно виконати навчальне завдання та отримати код доступу.

### **3\. Створіть 5 завдань**

Заповніть таблицю:

| Рівень | Завдання | Бали |
| ----- | ----- | ----- |
| 1 | Просте запитання або тест | 10 |
| 2 | Знайти правильну відповідь | 10 |
| 3 | Виконати практичне завдання | 20 |
| 4 | Розв'язати проблему | 20 |
| 5 | Фінальне завдання | 30 |

**Максимальна кількість — 90 балів.**

### **4\. Придумайте нагороди**

Визначте результат проходження квесту:

* **70–90 балів** — 🏆 «Майстер квесту»;  
* **50–69 балів** — ⭐ «Дослідник»;  
* **30–49 балів** — 🎯 «Новачок».

Можна придумати власні назви нагород.

### **5\. Візуалізуйте квест**

Створіть просту схему проходження:

**Старт → Рівень 1 → Рівень 2 → Рівень 3 → Рівень 4 → Фінал → Нагорода**

Оформити її можна в Canva, PowerPoint, Google Slides або намалювати у вигляді схеми.

## **Що потрібно здати**

Студент подає **1–2 сторінки або 3–5 слайдів**, де зазначено:

1. Назву та тему квесту.  
2. Коротку легенду.  
3. П'ять навчальних завдань.  
4. Кількість балів за кожне завдання.  
5. Нагороди.  
6. Схему проходження квесту.

## **Оцінювання**

| Критерій | Бали |
| ----- | ----- |
| Ідея та легенда квесту | 3 |
| Якість 5 завдань | 3 |
| Система балів і нагород | 3 |
| Оформлення | 3 |
| **Разом** | **12** |

### **Питання для захисту**

1. Яка навчальна мета вашого квесту?  
2. Чому ви обрали саме такі завдання?  
3. Які елементи гейміфікації використані?  
4. Як квест може підвищити інтерес студентів до навчання?
