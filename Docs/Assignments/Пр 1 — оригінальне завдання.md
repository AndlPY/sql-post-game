# **Практична робота №1**

## **Створення проєкту гейміфікації процесу навчання**

### **Тема**

Розроблення концепції гейміфікації навчального процесу.

### **Мета роботи**

Ознайомитися з основними принципами гейміфікації та навчитися проєктувати систему ігрових механік для підвищення мотивації, активності та залученості студентів у навчальний процес.

### **Завдання**

Розробити власний **проєкт гейміфікації навчального курсу або окремої навчальної дисципліни**.

Проєкт має перетворити традиційний процес навчання на систему, у якій студент отримує бали, досягнення, рівні, нагороди або інші ігрові стимули за виконання навчальних завдань.

## **Хід роботи**

### **1\. Обрати навчальну дисципліну**

Оберіть одну дисципліну, для якої буде створюватися система гейміфікації.

**Приклади:**

* Програмування;  
* Веброзробка;  
* Математика;  
* Іноземна мова;  
* Історія;  
* Маркетинг;  
* Комп'ютерна графіка;  
* Управління проєктами.

Вкажіть:

* назву дисципліни;  
* цільову аудиторію;  
* тривалість курсу;  
* основні результати навчання.

### **2\. Визначити проблему**

Проаналізуйте, які проблеми навчальної мотивації має вирішити гейміфікація.

Наприклад:

* низька активність студентів;  
* пропуски занять;  
* несвоєчасне виконання завдань;  
* відсутність інтересу до теоретичного матеріалу;  
* страх складних завдань;  
* недостатня взаємодія між студентами.

Визначте **2–4 основні проблеми**.

### **3\. Сформулювати цілі гейміфікації**

Сформулюйте щонайменше **3 конкретні цілі**.

Наприклад:

> Підвищити кількість виконаних домашніх завдань на 20%.

> Заохотити студентів регулярно повторювати навчальний матеріал.

> Підвищити активність студентів під час практичних занять.

Цілі мають бути конкретними та такими, що їх можна оцінити.

### **4\. Створити ігровий сюжет**

Придумайте **тему або сюжет**, у межах якого відбуватиметься навчання.

Наприклад:

* студенти — члени команди, яка створює стартап;  
* студенти — дослідники, які проходять наукову експедицію;  
* студенти — герої, які проходять рівні та отримують нові навички;  
* студенти — працівники IT-компанії, які виконують проєктні місії.

Опишіть сюжет у **5–7 реченнях**.

### **5\. Розробити ігрові механіки**

Оберіть щонайменше **5 ігрових механік**, які будуть використовуватися у вашому проєкті.

Можна використати:

| Ігрова механіка | Приклад використання |
| ----- | ----- |
| Бали | За правильну відповідь — 10 балів |
| Рівні | Після 100 балів студент переходить на новий рівень |
| Значки | «Експерт», «Швидкий старт», «Майстер практики» |
| Рейтинг | Таблиця лідерів групи |
| Квести | Виконання комплексу навчальних завдань |
| Місії | Виконання практичного завдання |
| Нагороди | Додаткові бонуси за досягнення |
| Віртуальна валюта | Монети для отримання бонусів |
| Командні змагання | Змагання між командами |
| Серії досягнень | Бонус за виконання завдань кілька тижнів поспіль |
| Боси | Підсумкові складні завдання після завершення теми |

Для кожної механіки поясніть:

1. що отримує студент;?\!\!\!  
2. за яку дію;?\!\!\!  
3. скільки балів/нагород нараховується;?\!\!\!  
4. як ця механіка впливає на мотивацію?\!\!\!

### **6\. Створити систему балів**

Розробіть власну систему нарахування балів.

Наприклад:

| Активність | Кількість балів |
| :---- | :---- |
| Виконання домашнього завдання | \+20 |
| Правильна відповідь на занятті | \+5 |
| Практична робота | \+30 |
| Додаткове завдання | \+15 |
| Допомога іншому студенту | \+10 |
| Виконання завдання достроково | \+10 |
| Порушення дедлайну | −5 |

Визначте, **за які дії бали можна отримати та за які можна втратити**.

### **7\. Розробити рівні**

Створіть щонайменше **5 рівнів прогресу**.

Наприклад:

| Рівень | Назва | Необхідна кількість балів |
| :---- | :---- | :---- |
| 1 | Новачок | 0 |
| 2 | Учень | 100 |
| 3 | Дослідник | 250 |
| 4 | Експерт | 450 |
| 5 | Майстер | 700 |

Для кожного рівня придумайте власну назву та короткий опис.

### **8\. Розробити систему нагород**

Створіть щонайменше **5 нагород або досягнень**.

Наприклад:

* 🏆 «Перше досягнення» — виконано перше завдання;  
* ⚡ «Швидкий старт» — виконано 5 завдань достроково;  
* 🎯 «Влучний студент» — 10 правильних відповідей поспіль;  
* 🤝 «Командний гравець» — допомога команді;  
* 🧠 «Експерт» — успішно виконано всі завдання певної теми.

Для кожної нагороди зазначте **умову отримання**.

### **9\. Створити приклад навчального квесту**

Розробіть **один повноцінний квест** для вашої дисципліни.

Вкажіть:

**Назва квесту:**  
**Мета:**  
**Передумови:**  
**Завдання:**  
**Кількість етапів:**  
**Максимальна кількість балів:**  
**Нагорода:**  
**Критерії успішного проходження:**

Квест повинен бути пов'язаний із реальними навчальними результатами дисципліни.

### **10\. Створити прототип системи**

Представте, як виглядатиме ваша система гейміфікації.

Можна створити:

* макет у Canva;  
* презентацію;  
* таблицю в Excel/Google Sheets;  
* прототип вебсторінки;  
* схему в Miro/Figma;  
* інший зручний формат.

Прототип повинен містити щонайменше:

**профіль студента → рівень → кількість балів → прогрес → досягнення → доступні квести → нагороди.**

## **Додаткове завдання ⭐**

Розробіть **систему антигейміфікації**, тобто визначте, які елементи вашої системи можуть негативно впливати на мотивацію студентів.

Наприклад:

* надмірна конкуренція;  
* демотивація студентів із низькими результатами;  
* маніпуляція балами;  
* надмірна орієнтація на винагороду;  
* нерівні можливості для студентів.

Запропонуйте **не менше 3 способів**, як уникнути цих проблем.

4. Чому саме ці механіки ви обрали?

9. Що відбудеться, якщо студент втратить мотивацію або перестане брати участь?

### **Логічний результат роботи**
